# Preset Launcher

Приложение для Windows и macOS, которое переключает рабочее окружение одним действием. Пресет - это набор программ: при переключении нужные запускаются, а лишние из других пресетов корректно закрываются.

Например, пресет «Работа» открывает IDE, браузер с рабочими вкладками и мессенджер, а пресет «Игры» закрывает всё это и запускает Discord и Steam. Переключать можно из меню в трее, из командной строки или удалённо по HTTP API (Home Assistant, голосовой ассистент).

Написано на Rust, интерфейс на egui. Один небольшой exe, установка без прав администратора.

## Возможности

- Пресеты из произвольных программ: `.exe`, ярлыки `.lnk`, URL и протоколы (`steam://...`), переменные `%ENV%` в путях.
- Порядок запуска и пауза после каждой программы; уже запущенные пропускаются (или запускаются повторно, например браузер с рабочими вкладками).
- Корректное закрытие: сначала `WM_CLOSE` или собственная команда (например `steam.exe -shutdown`), по таймауту - принудительное завершение (настраивается для каждой программы).
- Программы, общие для старого и нового пресета, не перезапускаются.
- Значок в трее: список пресетов с отметкой активного, быстрое переключение.
- Автозапуск при входе в Windows свёрнутым в трей, с необязательным стартовым пресетом.
- HTTP API: статус, переключение, питание ПК (выключение, сон, гибернация, блокировка, перезагрузка) с отменой, громкость, медиаклавиши, уведомления.
- Конфиг в читаемом TOML, журнал в файле.

## Установка

### Установщик

Скачайте `PresetLauncher-Setup-<версия>.exe` со страницы релизов и запустите. Установка выполняется в профиль пользователя (`%LOCALAPPDATA%\Programs\Preset Launcher`), права администратора не нужны. В мастере можно отметить автозапуск и значок на рабочем столе. Конфигурация в `%APPDATA%\PresetLauncher` при удалении программы сохраняется.

### Сборка из исходников

Нужны Windows и [Rust](https://rustup.rs/) (stable).

```powershell
cargo build --release
# результат: target\release\preset-launcher.exe
```

Установщик собирается скриптом (нужен [Inno Setup 6](https://jrsoftware.org/isinfo.php), `winget install JRSoftware.InnoSetup`):

```powershell
.\build-installer.ps1
# результат: installer\Output\PresetLauncher-Setup-<версия>.exe
```

Тосты `POST /api/notify` без установщика могут не показываться: им нужен ярлык в меню «Пуск» с AppUserModelID `PresetLauncher.App`, который создаёт установщик.

## Быстрый старт

1. Запустите программу. При первом запуске создаются два примера - «Работа» и «Игры» - из программ, найденных на ПК.
2. В окне создайте или отредактируйте пресет: добавьте программы, укажите путь, аргументы, имя процесса, задержку, правила закрытия.
3. Переключайтесь между пресетами из окна или из меню значка в трее (правая кнопка мыши). Закрытие окна сворачивает программу в трей, «Выход» в меню завершает её.
4. Для автозапуска отметьте соответствующую задачу в установщике. Запись добавляется в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и запускает `preset-launcher.exe --autostart`. Если в настройках задан `startup_preset`, он применяется при таком запуске.

Параметры командной строки:

| Параметр | Действие |
|---|---|
| `--autostart` | запуск свёрнутым в трей; применяет `startup_preset` |
| `--minimized` | запуск свёрнутым в трей |
| `--preset ИМЯ` | переключиться на пресет (если программа уже запущена, команда передаётся ей) |

Программа работает в одном экземпляре: повторный запуск показывает окно уже работающего.

Формат конфигурации: [docs/CONFIG.md](docs/CONFIG.md).

## Удалённое управление

1. В окне найдите блок «Удалённое управление» и включите API. Если токен пуст, он создаётся автоматически (64 hex-символа); «Новый токен» выпускает другой, прежний сразу перестаёт работать.
2. Порт по умолчанию - **47800**, сервер слушает на всех интерфейсах (`0.0.0.0`). Включение и смена порта применяются без перезапуска.
3. Разрешите входящие подключения в брандмауэре Windows только для локальной сети (PowerShell от администратора):

```powershell
New-NetFirewallRule -DisplayName "Preset Launcher API" -Direction Inbound `
  -Protocol TCP -LocalPort 47800 -Action Allow `
  -RemoteAddress 192.168.1.0/24 -Profile Any
```

Подставьте свою подсеть вместо `192.168.1.0/24`.

4. Проверка:

```powershell
$h = @{ Authorization = "Bearer <токен>" }
Invoke-RestMethod http://192.168.1.10:47800/api/status -Headers $h
```

Справочник по эндпоинтам и пример интеграции с Home Assistant: [docs/API.md](docs/API.md).

## Безопасность

- Все запросы требуют заголовок `Authorization: Bearer <токен>`. Токен сравнивается за постоянное время; пустой токен в настройках никого не авторизует. Тело запроса не читается, пока авторизация не пройдена.
- API рассчитан на **локальную сеть**. Это обычный HTTP без TLS: токен передаётся открытым текстом. Не пробрасывайте порт в интернет и не открывайте его без ограничения по адресам. Для доступа извне используйте VPN.
- Через API можно выключить ПК, изменить громкость и запустить любой настроенный пресет. Храните токен как пароль и не публикуйте его (в конфигах Home Assistant используйте `!secret`).
- Лимиты: тело запроса не более 16 КБ; не более 8 одновременных запросов (сверх - `503 busy`); не более 4 одновременно показываемых уведомлений. Запросы с оборванным телом не выполняются.
- Выключение и перезагрузка выполняются без `/f`: программы с несохранёнными данными могут задержать завершение, но данные не теряются.

## Кастомизация

В окне, блок **«Внешний вид»**:

- **Тема** — системная (следует теме ОС), светлая или тёмная.
- **Акцент** — цвет выделения, ссылок и маркера активного пресета (по умолчанию `#3CC88A`, кнопка «Сброс» возвращает его).

В редакторе пресета:

- **Иконка** — эмодзи или 1–2 символа; показывается в списке пресетов и префиксом в меню трея.
- **Цвет** — цветная метка пресета в списке.
- **Горячая клавиша** — глобальное сочетание, например `Ctrl+Alt+1`. Обязателен хотя бы один модификатор.

Горячие клавиши **по умолчанию выключены**: включаются флажком в настройках (`hotkeys_enabled`).
Пока они выключены, приложение ничего не регистрирует в системе. Ошибки (неверная строка, сочетание занято
другой программой, одно сочетание у двух пресетов) показываются под полем и пишутся в журнал; работают и при окне,
свёрнутом в трей. Все поля — в [docs/CONFIG.md](docs/CONFIG.md#новые-поля-040).

## Журнал и уровни логирования

Журнал — `launcher.log` рядом с `config.toml`. Кнопка **«Открыть журнал»** открывает его в программе по умолчанию.

| Уровень | Что пишется |
|---|---|
| `error` | только ошибки: запуск/закрытие программ, конфиг, трей, API (питание, громкость, уведомления, занятый порт), горячие клавиши |
| `info` (по умолчанию) | + переключения пресетов, запуски, принудительные завершения, команды API, регистрация горячих клавиш |
| `debug` | + шаги закрытия процессов и каждый HTTP-запрос в виде `API: METHOD /path -> код` (без токена, тела и query-строки) |

Формат строки: `HH:MM:SS текст`; ошибки помечаются `[ERR]`, отладка — `[DBG]`.
Уровень меняется на лету. Когда файл превышает 1 МБ, он переименовывается в `launcher.log.old` (хранится одна старая копия).

## macOS и Siri

С версии 0.5.0 есть сборка для macOS (Apple Silicon и Intel, один universal `.app`): пресеты, меню в строке меню,
горячие клавиши, HTTP API и CLI. Приложение не подписано сертификатом Apple — при первом запуске
правый клик → «Открыть» (или `xattr -dr com.apple.quarantine "Preset Launcher.app"`).
Не поддерживаются гибернация и медиаклавиша `stop` (API отвечает `501`). Подробности и нужные разрешения —
[docs/MACOS.md](docs/MACOS.md).

**Siri** работает через «Быстрые команды»: команда с действием «Получить содержимое URL» вызывает HTTP API,
а её имя становится фразой — «Привет, Siri, Работа». Так можно управлять и Mac, и Windows-ПК с iPhone в той же сети.
Пошагово — [docs/SIRI.md](docs/SIRI.md).

**CLI** (Windows и macOS) управляет уже запущенным экземпляром:

```sh
preset-launcher switch Работа
preset-launcher status
preset-launcher list --json
```

Все команды — [docs/CLI.md](docs/CLI.md).
