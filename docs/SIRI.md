# Siri и «Быстрые команды»

Preset Launcher не нужно «учить» Siri: достаточно создать **быструю команду**, которая отправляет запрос в его HTTP API (подробнее об API - в [API.md](API.md)). Название быстрой команды и есть фраза для Siri: если назвать команду «Работа», то «Привет, Siri, Работа» переключит пресет.

Подходит и Mac, и iPhone/iPad (программа «Быстрые команды» есть на обоих).

## Что понадобится

1. Запущенный Preset Launcher с **включённым API** (блок «Удалённое управление»).
2. **Токен** - он показан в окне программы (кнопка копирования).
3. **Порт** - по умолчанию `47800`.
4. Адрес:
   - команда на **том же Mac**, где работает Preset Launcher: `127.0.0.1`;
   - команда на iPhone/iPad или на другом Mac, а Preset Launcher на ПК с Windows (или другом Mac): адрес этого компьютера в локальной сети, например `192.168.1.10` (в окне программы он написан рядом с настройками API). Пишите его как `<IP-ПК>`. Телефон и компьютер должны быть в одной сети (Wi-Fi/LAN). Если компьютер не отвечает, разрешите входящие подключения на порт `47800` в брандмауэре.

## Быстрая команда «Работа» (переключение пресета)

1. Откройте **Быстрые команды** → **+** (новая команда).
2. Нажмите на название вверху и введите фразу для Siri, например **Работа**.
3. **Добавить действие** → найдите **«Получить содержимое URL»** (Get Contents of URL).
4. В поле URL введите:
   - `http://127.0.0.1:47800/api/switch` - если команда выполняется на Mac с Preset Launcher;
   - `http://<IP-ПК>:47800/api/switch` - если на другом устройстве.
5. Нажмите **Показать больше** (стрелка) и задайте:
   - **Метод:** `POST`.
   - **Заголовки** → **Добавить новый заголовок** (два раза):
     - `Authorization` = `Bearer <токен>` (слово `Bearer`, пробел, затем ваш токен);
     - `Content-Type` = `application/json`.
   - **Тело запроса:** `JSON` → **Добавить новое поле** → тип **Текст**, ключ `preset`, значение `Работа` (точное имя пресета из программы, с учётом регистра).

   Если в вашей версии удобнее тело «Файл»/«Текст»: выберите **Тело запроса: Файл** и вставьте в действие «Текст» строку `{"preset": "Работа"}`.
6. Нажмите ▶, чтобы проверить. В Preset Launcher должен запуститься выбранный пресет. Код ответа `202` - всё хорошо; `401` - неверный токен; `404` - в программе нет пресета с таким именем.
7. Скажите: **«Привет, Siri, Работа»**.

Для каждого пресета повторите (или продублируйте команду и поменяйте название и значение `preset`).

> Первый запуск команды, обращающейся к сети, iOS может подтвердить диалогом «Разрешить» - согласитесь.

## Другие команды

Все они - то же действие «Получить содержимое URL» с методом `POST`, теми же двумя заголовками и другим адресом и телом. Меняются только URL и JSON.

| Что сделать | URL (после `http://<адрес>:47800`) | Тело JSON |
|---|---|---|
| выключить компьютер через минуту | `/api/shutdown` | `{"delay_secs": 60}` |
| отменить выключение | `/api/shutdown/cancel` | (пусто) |
| сон | `/api/power` | `{"action": "sleep", "delay_secs": 0}` |
| заблокировать | `/api/power` | `{"action": "lock"}` |
| перезагрузка | `/api/power` | `{"action": "restart"}` |
| громкость 30 % | `/api/volume` | `{"level": 30}` |
| тише на 10 | `/api/volume` | `{"delta": -10}` |
| выключить звук | `/api/volume` | `{"muted": true}` |
| пауза/воспроизведение | `/api/media` | `{"action": "play_pause"}` |
| уведомление на компьютере | `/api/notify` | `{"title": "Привет", "message": "С телефона"}` |

Назовите команды как хотите произносить: «Выключи компьютер», «Сон», «Громче».

Примечания:

- Если целевой компьютер - **Mac**, то `hibernate` и медиа `stop` не поддерживаются (ответ `501`), а блокировка и перезагрузка требуют разрешений - см. [MACOS.md](MACOS.md).
- Выключение лучше делать с задержкой (`delay_secs`): так его можно отменить командой `shutdown/cancel` (или переключением пресета).
- Тело `{"delay_secs": 0}` выполнит действие немедленно.

## Альтернатива на Mac: «Выполнить shell-скрипт»

Если Preset Launcher стоит на том же Mac, вместо сетевого действия можно использовать консольную команду ([CLI.md](CLI.md)) - токен вводить не нужно:

1. Добавьте действие **«Выполнить shell-скрипт»** (Run Shell Script).
2. Оболочка `/bin/zsh`, в поле скрипта:

   ```sh
   "/Applications/Preset Launcher.app/Contents/MacOS/preset-launcher" switch "Работа"
   ```
3. Назовите команду «Работа» - и Siri заработает так же.

## Безопасность

- API работает **без шифрования** (HTTP) и слушает все сетевые интерфейсы. Используйте его **только в доверенной локальной сети**; не пробрасывайте порт в интернет.
- **Токен - это пароль.** Любой, кто знает токен и может достучаться до порта, управляет вашим компьютером (в том числе выключает его). Не публикуйте скриншоты команд с токеном, не отправляйте быстрые команды другим людям: токен хранится внутри команды. Если токен утёк, нажмите «Новый токен» в программе и обновите команды.
- Если нужен только доступ с этого же Mac, адрес `127.0.0.1` вообще не выходит в сеть; при желании отключите входящие подключения для приложения в брандмауэре.
