# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.5.0]

### Добавлено
- Сборка для macOS (universal `.app`): процессы через NSRunningApplication, питание через `pmset`/System Events,
  громкость и уведомления через `osascript`, медиаклавиши, автозапуск через LaunchAgent.
- CLI: `switch`, `status`, `list` (управляют запущенным экземпляром через локальный API), `autostart` на macOS.
- Siri через «Быстрые команды» (docs/SIRI.md).
- GitHub Actions: CI для Windows и macOS, релиз по тегу `v*` (установщик Windows и zip для macOS).

### Изменено
- Платформенный код вынесен в `src/platform/{win,mac}`; на macOS неподдерживаемые действия API отвечают `501`.

## [0.4.0]

### Добавлено
- Тема окна (системная / светлая / тёмная) и цвет акцента.
- Иконка и цвет у пресета: в списке и в меню трея.
- Глобальные горячие клавиши пресетов (по умолчанию выключены).
- Уровни журнала `error` / `info` / `debug`, кнопка «Открыть журнал», ротация `launcher.log` по 1 МБ.
- В журнале уровня `debug` — каждый HTTP-запрос API (без токена и тела).

## [0.3.0]

### Добавлено
- API: `POST /api/power` (`sleep`, `hibernate`, `lock`, `restart`) с отложенным выполнением.
- API: `POST /api/volume` (уровень, шаг, mute), `POST /api/media` (медиаклавиши), `POST /api/notify` (Windows toast).
- `GET /api/status` дополнен полями `pending_power`, `volume`, `muted`.
- Одно ожидающее действие питания на все виды; `POST /api/shutdown/cancel` отменяет любое из них.

### Безопасность и надёжность
- Используется локальная копия `tiny_http` 0.12.0 (`vendor/`) с исправлением Drop у `EqualReader`: аллокация размером с `Content-Length` могла аварийно завершить процесс.
- Токен проверяется до чтения тела; сравнение за постоянное время.
- Тело ограничено 16 КБ; запросы с оборванным телом не выполняются; не более 8 одновременных запросов (сверх - `503`).
- Не более 4 одновременных тостов (`503 busy`); текст уведомления экранируется как XML.

## [0.2.0]

### Добавлено
- Локальный HTTP API (порт по умолчанию 47800, Bearer-токен): `GET /api/status`, `POST /api/switch`, `POST /api/shutdown` (отменяемая задержка 0-600 с), `POST /api/shutdown/cancel`.
- Раздел «Удалённое управление» в окне: включение API, порт, токен, «Новый токен». Изменения применяются без перезапуска.
- Поддержка интеграции с Home Assistant и голосовыми ассистентами.

## [0.1.0]

### Добавлено
- Пресеты: наборы программ с запуском по порядку и паузой `delay_ms`.
- При переключении закрываются программы других пресетов: мягко (`WM_CLOSE` или собственная `close_command`), затем принудительно по таймауту.
- Значок в трее с меню пресетов, окно настроек на egui.
- Запуск `--autostart` (свёрнутым, со стартовым пресетом), `--preset NAME`, один экземпляр приложения.
- Установщик Inno Setup (установка для пользователя без прав администратора, автозапуск).
